# Juicy Games Studio

Juicy Games Studio is an indie game development project focused on colorful, character-driven games.

## Current Project

### Cupcake Girl

A side-scrolling adventure game set in a dessert-themed world filled with dessert heroes, strange enemies, boss battles, and vivid environments.

## Development Focus

- Unreal Engine 5
- C++ and Blueprints
- 2D / 2.5D side-scrolling gameplay
- Character-driven worldbuilding
- Cross-platform game systems

## Status

Early development and prototyping.
