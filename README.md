# Juicy Games Studio

Independent game development studio creating colorful, character-driven games.

**Website:** https://juicygames.carrd.co/

## Games and projects

### Cupcake Girl Match Quest
A candy-themed matching game developed in Godot 4. Current development focuses on mobile and desktop builds, testing, and gameplay improvements.

- [Play the alpha on itch.io](https://juicygames101.itch.io/match-quest)
- [Game developer profile](https://juicygames101.itch.io/)
- [Source repository (private)](https://github.com/JuicyGamesStudio/CupcakeMatchQuest-Godot)

### Cupcake Girl 2D / side-scroller prototype
A separate side-scrolling game prototype. The GitHub repository currently contains a **Godot 4** project (scenes, scripts, assets and tools). Any newer Unreal Engine work is not confirmed by this repository.

- [CCG2D source repository (private)](https://github.com/JuicyGamesStudio/CCG2D)
